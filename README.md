## 1. Назначение и предметная область

Программный комплекс предназначен для алгоритмической обработки и экспресс-анализа временных рядов замеров суточного дебита нефтяной скважины ($Q$, м³/сут) на чистом Python 3.11+.

### Ключевые возможности:
- **Чистое математическое ядро (`analytics.py`):** полный отказ от внешних библиотек (`numpy`, `pandas`, `statistics`) и встроенных агрегатов (`min()`, `max()`, `sum()`). Все операции выполняются на базе одномерных циклов, аккумуляторов и срезов.
- **Робастный статистический анализ:** расчёт среднего арифметического, неискажающей медианы для чётной и нечётной длины ряда, нахождение минимума, максимума и размаха вариации ($R$) за один проход ($O(n)$).
- **Сглаживание методом скользящей средней (SMA):** реализация алгоритма с поддержкой окон произвольной ширины ($k_1 = 3$ и $k_2 = 5$ суток), выравнивание размерности массива с заполнением фазы накопления значениями `None`.
- **Оценка тренда и псевдографика:** определение направленности динамики дебита (восходящий/нисходящий/стабильный) и рендеринг текстового профиля дебита (`#`) в терминале.
- **Прикладная бизнес-аналитика:** вычисление суммарной добычи ($Q_{sum}$), доли пикового дня в общем объёме и фильтрация высокодебитных суток.

## 2. Математическая модель и параметры варианта (N = 69)

### 2.1. Формирование индивидуального ряда
Параметры дебита рассчитываются по индивидуальному номеру $N = 69$:
- Базовый уровень дебита ($B$):
  $$B = 55.0 + 2.5 \cdot N = 55.0 + 2.5 \cdot 69 = 227.5\text{ м}^3/\text{сут}$$
- Амплитуда суточных колебаний ($S$):
  $$S = (N \pmod 4) + 1.5 = (69 \pmod 4) + 1.5 = 1.0 + 1.5 = 2.5\text{ м}^3/\text{сут}$$
- Вектор суточных коэффициентов отклонения ($\text{OFFSETS}_{12D}$):
  $$[0.0,\; 1.0,\; -1.0,\; 2.0,\; 0.0,\; -2.0,\; 1.0,\; 8.0,\; -1.0,\; 2.0,\; 1.0,\; 3.0]$$

Значение дебита на сутки $i$ ($i = 1 \dots 12$):
$$Q_i = B + S \cdot \text{OFFSETS}_{12D}[i - 1]$$

Итоговый хронологический ряд $Q$ (12 суток):
$$[227.50,\; 230.00,\; 225.00,\; 232.50,\; 227.50,\; 222.50,\; 230.00,\; 247.50,\; 225.00,\; 232.50,\; 230.00,\; 235.00]$$

### 2.2. Расчётные формулы
1. **Суммарная добыча:**
   $$Q_{sum} = \sum_{i=1}^{n} Q_i = 2765.00\text{ м}^3$$
2. **Среднее арифметическое:**
   $$\bar{Q} = \frac{Q_{sum}}{n} = \frac{2765.00}{12} \approx 230.42\text{ м}^3/\text{сут}$$
3. **Медиана (чётная длина $n = 12$, индексы 5 и 6 упорядоченного ряда):**
   $$Me = \frac{Q_{(6)} + Q_{(7)}}{2} = \frac{230.00 + 230.00}{2} = 230.00\text{ м}^3/\text{сут}$$
4. **Размах вариации ($R$):**
   $$R = Q_{max} - Q_{min} = 247.50 - 222.50 = 25.00\text{ м}^3/\text{сут}$$
5. **Простая скользящая средняя (Simple Moving Average, SMA):**
   $$SMA(k)_t = \frac{1}{k} \sum_{j=0}^{k-1} Q_{t-j}$$
   Длина результирующего сглаженного ряда: $L = n - k + 1$.

## 6. Краткие итоги обязательных упражнений (Раздел 8)

1. **Упр. 1 (Нечётная длина ряда):** при добавлении замера $60.0$ ($n = 13$) оно занимает нулевую позицию отсортированного списка, а медианой становится центральный элемент с индексом $13 // 2 = 6$, равный $230.00$ м³/сут.
2. **Упр. 2 (Устойчивость к выбросу):** замена замера 12-х суток на $500.0$ увеличивает среднее на $+22.08$ м³/сут ($230.42 \rightarrow 252.50$, в нормативной оценке $248.54$) и размах в 11 раз ($25.00 \rightarrow 277.50$), сохраняя медиану неизменной ($230.00$).
3. **Упр. 3 (Ширина окна $k$):** для $k=2$ длина ряда равна $12 - 2 + 1 = 11$ (размах $13.75$), для $k=5$ длина равна $12 - 5 + 1 = 8$ (размах $6.50$). Увеличение $k$ подавляет волатильность.
4. **Упр. 4 (Опасность `.sort()`):** сортировка по месту разрушает временную ось и превращает скользящую среднюю в монотонно возрастающий вектор $[224.17, 225.83, 226.67, \dots]$.
5. **Упр. 5 (Суммарная добыча):** $Q_{sum} = 2765.00$ м³, пик $247.50$ м³/сут, доля пика: $\frac{247.50}{2765.00} \cdot 100\% = 8.95\%$.
6. **Упр. 6 (Фильтрация дебита):** строго выше среднего ($230.42$ м³/сут) зафиксировано 4 суток ($[4, 8, 10, 12]$). Не равно $n/2$, так как ряд делит пополам медиана, а среднее завышено выбросом.
7. **Упр. 7 (Краевые случаи):** при $k=1$ список SMA тождественен исходному ряду; при $k=12$ вырождается в 1 точку $[230.42]$, равную среднему; при $k=20$ корректно генерируется `ValueError`.
